# WebStudio — HW-03

Домашнє завдання №3 з HTML/CSS для курсу GoIT.

## Що зроблено:
- Додано загальну сітку та обмеження ширини контенту через `.container` (1158px).
- Розставлено елементи за допомогою Flexbox (хедер, секції, картки, футер).
- Стилі розбито на окремі модульні CSS-файли в папці `css/`.
- Заголовок секції Features приховано через `.visually-hidden`.

## Структура файлів:
- `index.html` — основна розмітка
- `css/` — модульні файли стилів (common, header, hero, features, team, portfolio, footer)
- `images/` — фото команди та картки портфоліо
- `.prettierrc` — конфіг форматування

## Як запустити:
Просто відкрити `index.html` у браузері або через Live Server у VS Code.
